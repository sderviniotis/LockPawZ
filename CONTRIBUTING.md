# Contributing

LockPawZ is a personal fork and is not taking contributions. If you want the general-purpose
app, with a lock screen, agent alerts, phone relay and an update channel, use upstream
[Lockpaw](https://github.com/sorkila/lockpaw), which does.

If you fork this fork: keep `LICENSE`, keep the attribution to Erik Nielsen, and pick a name
that is not "Lockpaw".
